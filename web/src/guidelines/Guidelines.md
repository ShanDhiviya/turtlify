# Turtlify App Guidelines

## App Overview
Turtlify is a mobile-first wildlife identification app with a special focus on turtles and marine life. The app helps users identify species, learn about wildlife, and build a personal discovery library.

## Design System Guidelines

### Brand Identity
* **Primary Color**: Green tones (representing nature and turtles)
* **Secondary Color**: Blue tones (representing water/marine environments)
* **App Icon**: Turtle emoji 🐢
* **Tagline**: "Snap. Discover. Learn."

### Typography
* Use the base font-size of 14px as defined in globals.css
* Headings should use medium font weight (500)
* Body text should use normal font weight (400)

### Component Guidelines

#### Buttons
* Primary buttons should use green colors for nature theme
* Secondary buttons can use blue for water/marine theme
* Always include clear, action-oriented labels

#### Cards
* Use subtle shadows and rounded corners (radius: 0.625rem)
* Include wildlife-themed icons where appropriate
* Maintain consistent spacing and hierarchy

#### Navigation
* Keep mobile-first approach
* Use turtle and nature-themed icons
* Maintain easy thumb navigation on mobile devices

### Color Palette
* **Primary Green**: For main actions, nature elements
* **Ocean Blue**: For marine life, water elements  
* **Neutral Grays**: For text and subtle backgrounds
* **Success Green**: For positive actions (species identified, saved)
* **Warning Orange**: For conservation status alerts

### Imagery
* Use high-quality wildlife photos
* Prioritize turtle and marine life imagery
* Ensure images are optimized for mobile viewing
* Use Unsplash for stock wildlife photography

### Iconography
* Prefer nature and wildlife themed icons
* Use Lucide React icon library
* Maintain consistent icon sizing (w-5 h-5 for most cases)
* Use turtle emoji 🐢 for app branding

## User Experience Guidelines

### Mobile-First Design
* Design for thumb navigation
* Ensure touch targets are at least 44px
* Optimize for one-handed use
* Use bottom navigation for primary actions

### Wildlife Focus
* Emphasize turtle and marine life content
* Use conservation messaging appropriately
* Include educational content about wildlife
* Support citizen science initiatives

### Performance
* Optimize images for mobile
* Use progressive loading for large datasets
* Implement smooth transitions between screens
* Cache identified species for offline access
